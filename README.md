# Part 2 - SQL Query Implementation and Verification

This is Part 2 of the CodeJudge Database Assignment.
It contains 20 SQL queries written on the CodeJudge dataset.

## Files
- queries.sql - all 20 SQL queries with comments
- query_outputs.md - sample outputs for each query
- sql_reasoning.md - explanations of query decisions
- README.md - this file

## How to Run
sqlite3 codejudge_raw.db < queries.sql

## Database
All queries run on codejudge_raw.db which is loaded from CSV files.
